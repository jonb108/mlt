VB Message Library Admin

This administrative site is only for special moderators of the VB Message Library not the public.

Deleting Messages

Search for a keyword. See the list of messages. Check one or more of the messages (click on the little square or the date NOT the message itself). Click on Delete Checked Messages.

Editing A Message

Search for a keyword. See the list of messages. Click on the message itself. See the dialog with the date, count, message, brigade name, city, and state. Change whatever you wish. Click on Submit.

Deleting Topics

Click on Topics. See the list of Topics. Check one or more topics by clicking on the little squares - NOT on the topic description. Click on Delete Checked Topics.

Editing a Topic

Click on Topics. See the list of Topics. Click on one of the topic descriptions. See the dialog with the topic description. Edit it however you wish. Click on Submit.

Collapsing Messages that differ only in Punctuation

Message 'clutter' happens when you have messages like these: 
RELEASE FILES NOT BOMBS!
RELEASE FILES | NOT BOMBS!
RELEASE FILES NOT BOMBS
These messages differ only in punctuation. Ideally, you would only have one of them.

If you enter the string SL in the search text field you will see sets of messages that have the Same Letters and differ only in punctuation. There will be a small text field before each message and a Submit button at the bottom. In each set of messages you can choose any one of them to represent the others and delete the rest like so: 

2  RELEASE FILES NOT BOMBS!
d  RELEASE FILES | NOT BOMBS!
d  RELEASE FILES NOT BOMBS
The first one will have its 'count' field increased by 2 to indicate that 2 other messages were similar. The second and third ones will be deleted.

Note that if messages have a count > 1 it will be shown in red. Here is another example: 

MY BODY, MY CHOICE 3
MY BODY = MY CHOICE
MY BODY. MY CHOICE. 2
MY BODY MY CHOICE 4
Choosing the last one as "best" you would add 6 (3+1+2) to the count of the last one and delete the other 3. 
d  MY BODY, MY CHOICE 3
d  MY BODY = MY CHOICE
d  MY BODY. MY CHOICE. 2
6  MY BODY MY CHOICE 4

Regeneration

After several deletions and other edits you should ensure that the topics and counts are accurate by clicking on Regen. This will tidy things up.

Viewing the VB Message Library

You can click on the title at the top (VB Message Library Admin) and you will see the VB Message Library site as non-admin people see it.
