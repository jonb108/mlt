VB Message Library

Introduction

This library is a database of messages that have been displayed on overpasses by Visibility Brigades (VB) around the nation. You can add messages and you can search for them in several ways. Messages can be assigned topics and you can see all messages within a given topic. The information here is 'crowdsourced'. It's up to you to contribute, maintain, and organize it. The library lives here:
    VBmessages.org

Choosing Messages for the Overpass

We all want to choose messages that are timely and relevant and potent and succinct. There is often a creative desire to create our own message - one that we came up with. Sharing is also a good thing and a message that works well in Maryland will also be effective in Arizona or Arkansas or Georgia or Montana! This is where this library can be useful. Plus, one can find a good message in the VB Message Library and then tweak it to make it better. For example, the message:

YOUR TAX $$ FUND THIS WAR

is quite good and it can be slightly altered to:

YOUR TAX $$ FUND HIS WAR

which is better, yes?

The Secret Keyword

This message library is wide open to the public for read-only enjoyment and inspiration.

However, if you want to modify the data in the library by adding a message, adding a new topic, adding topics to a message, or importing a file of messages, you will need to supply a secret keyword. This keyword will be supplied to all trusted Visibility Brigade leaders and, (assuming they trust you 😊), you can get the keyword from them. The keyword will also be shared in the VB Signal chat.

If this secret keyword is causing you some annoying trouble with your browser's "password manager" you can use this link instead:

    VBmessages.org/mlt
Note that this will cause the secret keyword to be openly displayed on the screen - which is nice, in a way, because you can SEE what you are typing! You will, however, want to be discreet and careful that no one can see your screen by "shoulder surfing".

Once you enter the correct keyword it will be stored in the browser data and will be subsequently filled in for you. You won't need to keep typing it over and over.

Messages

The 'home page' of the library shows the most recent 60 messages. You can always get to the home page by clicking on the large title VB Message Library at the top. After the 60 most recent messages there is a link 'Show All' which will load all of the messages into the browser. You generally won't do this because there are much better ways of perusing the messages!

Searching

You can search for a keyword in a message. Enter the search term in the text field and press Enter/Return.

The term will be highlighted in the messages that were found.

Matching messages are shown sorted by date so the newest messages are on top.

There is also a link entitled Search+ (Search Plus) with which you can search for messages in more complex ways.

For example, you could search for messages from a brigade in KS (Kansas) that are not more than 25 characters long, have 'dem' in the list of topics, and were displayed on an overpass in 2026 (1/1 through 12/31). As of 7/19/26 there were 3 such messages:

Adding

You can add a message with the link Add Message. You provide a date and the text of your messsage. The date is usually when the message was first displayed on an overpass. You are also asked for an optional Brigade Name, City, and State.

After the message is added you are asked what Topics apply to it. See below for an explanation of Topics.

Duplicate messages are handled in a special way. The date from the added message will be used if it is later than the date on the existing message but the message text, brigade name, city, and state will not change. The count of the message will be incremented.

The Brigade Name, City, and State are remembered for when you next add a message.

Topics

Topics are categories or themes - like Democracy or Justice. Or Corruption or Tariffs or Gun Control. They can be whatever you want. You can add new Topics and can assign one or more topics to messages.

From the home page (Messages) click on the link Topics and you will see the list of current topics.

Sorting Topics

The table of topics can be sorted by Topic (alphabetically) or by Count (decreasing). The order is down the first column and then on to the next columns.

Messages by Topic

Clicking on a topic name will show the messages which have that topic assigned to them. They are sorted by date.
A special topic is named "Needs Edit/Delete". Messages with this topic will be examined by a "moderator" to see if they need to be corrected or removed. If you added a message by mistake or see an error after adding it you can add this topic to it.

Adding

New topics are added with the link Add Topics. You can add 5 at once.

Applying Topics

After a message is added you are asked which topics (one or more) apply to the message:
Another way of assigning topics to a message is to simply click on a message that you see in the list. The check list of topics will be shown and you can choose the topics that apply to the message. If you think the message would be a great one for your own brigade to use, you can click on the message in this dialog to copy it to the clipboard. Then you can paste it wherever you wish.

Recent, Cities, Counts

There are 3 links on the home page:
  • Recent - Show the most recent messages (same as the home page).
  • Cities - Show the states and cities that have uploaded messages. The number of messages are also shown and you can click on that number to see the messages.
  • Counts - Show the counts of messages, topics, states, and cities.

Importing Messages

Messages can be added one by one with the Add Message link. More efficiently you can import a file of messages. Click on Import and you will see:
You are asked for a file of messages, two column letters, and an optional Brigade Name, City, and State that will apply to all imported messages.

The import file will usually be a .csv file (exported from a spreadsheet - comma separated values).

The spreadsheet will have column letters for the Date and the Message.

Here is an example of a .csv file where the column letters are A and B (the default):

    Date,Message
    05/06/25,POTUS IS PUTIN'S PUPPET
    11/27/25,HAPPY THANKSGIVING
And another where the column letters are B and D:
    Number,Date,Direction,Message
    1,05/06/25,Eastbound,POTUS IS PUTIN'S PUPPET
    2,11/27/25,Westbound,HAPPY THANKSGIVING

After the messages are imported you are asked to choose topics for each of them in sequence. If you imported many messages and don't have time to do all of the topic assignments for each of them you can simply click on the large Title at the top to return to the 'home page' and abort the topic assignment process. You can assign topics later by clicking on the messages or, even better, see the next section.

Messages with No Topics

It is important for messages to be tagged with appropriate Topics as this enables the very useful topic search as described above.

However, if one has added a message or done a large import of messages without setting topics there is a way to address these 'no topic' messages. Enter the term 'NT' (no topics) in the search text field and hit Enter. This will search for all messages without topics and ask you to set the applicable topics for each of them in sequence.

Duplicate Messages

This message library keeps just one instance of a message no matter how many different brigades have used it. If you add or import a message that is already in the library the date on the message will be set to the more recent date but the brigade name, city, and state will not be changed. Each message has a 'count'. Adding a duplicate message will increment the count of a message. Message counts that are greater than 1 will be displayed in red after the message.

Because of this unduplication when you search for messages from your particular brigade, the list of messages you see may not match the exact history of your brigade's messages. It is recommended that you keep this history in another place - such as your own spreadsheet or in the VB Letter Tool described below in the See Also section.

Almost Duplicate Messages

WELCOME TO WARFLATION
WELCOME TO WAR-FLATION
WELCOME TO WAR FLATION

Groups of messages like these which differ only in punctuation will be periodically collapsed into just one message with a cumulative count:

WELCOME TO WARFLATION  3

For your own brigade's use you can copy a message and then improve it with whatever punctuation you deem best.

Date Formats

When entering dates for messages you can use several formats:
    mm/dd/yy

    mm/dd = current year

    dd = current month

    T = today

    -3 = 3 days ago

Keyboard Shortcuts

In the search text field you can use these 'commands' to invoke various functions;

A Add Message
AT Add Topic
C Show Topics ordered by Count.
CS Show Cities and States and the number of messages that city has posted. Click on the numbers to see the messages.
CT Show counts of messages, topics, states, and cities.
I Import Messages from a .csv file
NT Add topics to Messages with No Topics
S Search Plus
T Show Topics ordered alphabetically.

See Also

Here is a little VB Letter Tool application to help manage a brigade's letters:
    VBmessages.org/lt
After a one-time initialization you can easily check whether you have enough letters to make a given message. You can also keep a historical list of the messsages you had on your bridge - and export them for importing here.

Ideas for Future Development

  1. What to do about messages or topics that are added by mistake or are inappropriate for some reason? We can't have a delete function available to everyone as someone with nefarious intent might delete good ones. It seems we need 'moderators' with the (password protected) ability to do the pruning - to "keep the tree healthy". You CAN add the topic "Needs Edit/Delete" and a moderator will deal with it.
  2. The national Signal chat named 'VB Message Brainstorming!' is a wonderful place for a free wheeling discussion of creative, timely, and potent message ideas. This library can be used for messages that a brigade has actually used on an overpass. There is no way to enforce this, of course, aside from moderators doing regular maintenance and pruning of unused messages.
  3. Any other ideas?
